# Google Play store listing draft

## App name

PlainNVR Companion

## Short description

Connect securely to your self-hosted PlainNVR server from Android.

## Full description

PlainNVR Companion puts your self-hosted PlainNVR system within easy reach on
Android. Connect directly to a PlainNVR server you control to view cameras,
review recordings, check recent events, and manage recorder status.

Features include:

- Live HLS camera viewing
- Recording calendar and MP4 playback
- Recent camera and recorder events
- Recorder start, stop, and restart controls
- Camera-advertised pan, tilt, zoom, home, and preset actions
- Direct connection to your own PlainNVR server

PlainNVR Companion does not connect directly to your cameras. Camera and
recording access goes through the PlainNVR server address you provide. The app
saves your server address and username on your device, but it does not save
your password. Session cookies are kept in memory and discarded when the app
process ends.

PlainNVR is free and open-source software. A separately installed and
configured PlainNVR server is required.

For remote access, use a properly secured HTTPS endpoint. Plain HTTP support is
intended only for trusted local networks.
