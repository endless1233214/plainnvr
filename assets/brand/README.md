# PlainNVR Brand Assets

This folder contains the source PlainNVR brand images used by the iPhone and macOS companion apps.

- `plainNVR_dark_1024.png` and `plainNVR_light_1024.png` are the primary logo marks.
- `splash_screens/` contains launch artwork for light and dark appearances.
- `macOS_dock_icons/` contains the macOS app icon sizes.
- `monochrome_icons/` contains single-color marks.
- `sf_symbol_style_icons/` contains small camera, grid, and recording symbols.
- `branding/plainNVR_branding_banner.png` is the wide banner artwork.
