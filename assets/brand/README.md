# PlainNVR Brand Assets

This directory contains the reusable PlainNVR artwork for repository
documentation and companion applications.

| Path | Purpose |
| --- | --- |
| `plainNVR_dark_1024.png` | Primary mark for dark backgrounds |
| `plainNVR_light_1024.png` | Primary mark for light backgrounds |
| `splash_screens/` | Launch artwork for light and dark appearances |
| `macOS_dock_icons/` | Generated macOS application icon sizes |
| `monochrome_icons/` | Single-color logo variants |
| `sf_symbol_style_icons/` | Small camera, grid, and recording interface symbols |
| `branding/plainNVR_branding_banner.png` | Wide repository and presentation banner |

Use the primary marks when a full-size logo is appropriate. Use the monochrome
or interface-symbol variants when the surrounding design controls color,
contrast, or icon size.
